Context

The BiggSinerji brief claims 87-98% utility, AUC=0.51 privacy, and superiority over
CTGAN/SMOGN. The initial thesis experiments were ad-hoc — different methods tested on
different datasets with no consistent comparison matrix. Phase 2 experiments must be
methodical: every method on every dataset, with a structured comparison framework.

Important: NormDigital datasets (Ozel Simple, Ozel Rich, Production Full) cannot be used
commercially. All Phase 2 experiments use public datasets only. Original thesis results
can be referenced as prior work.

Hardware: RTX 4070 Ti Super (16GB VRAM) via SSH for all GPU training. MacBook M5 (32GB)
for code writing, analysis, and report generation.

Model clarification: Our implementation builds on the TabDDPM architecture (Kotelnikov
et al., ICML 2023) with practical improvements:

- MinMaxScaler instead of QuantileTransformer (fixes invertibility)
- Outlier clipping (1st-99th percentile)
- Model capacity scaling with input dimensionality
- Bug fixes (categorical ratio explosion at high timesteps)
  These produced a 3.3x improvement over naive diffusion (26.5% → 87.3% utility).

Comparison Framework

Metrics (standardized for every experiment)

A. Utility Metrics (downstream ML task)

- R² (regression) or Accuracy + F1 (classification)
- 3 models: Random Forest, Gradient Boosting, Ridge/Logistic Regression
- 2 scenarios: Replacement (train on synthetic only) and Augmentation (real + synthetic)
- Report: absolute score + % of real-data baseline

B. Statistical Fidelity Metrics (distribution-level)

- Per numerical column: mean diff, std diff, Wasserstein distance, KL divergence, KS
  test p-value
- Overall: Correlation matrix Frobenius norm difference
- Per categorical column: category frequency difference (L1 norm)

C. Privacy Metrics

- Membership inference attack AUC
- Distance to Closest Record (DCR) distribution

Comparison Dimensions

Intra-experiment (within one dataset): 4 methods head-to-head — which wins?

Inter-experiment (across datasets): How does each method scale with dimensionality?
Where does SMOGN break? How does sample size affect results?

Ablation (Vanilla vs Our TabDDPM): What's the impact of each improvement? Does the gap
widen with complexity?

Output: A single 4D comparison matrix (method × dataset × metric × scenario).
